# Специфікація процесу: UC-5 «Оформити замовлення» та UC-6 «Обробити підтвердження оплати»

## 1. Намір та Межі (Scope)
- **Намір**: Описати бізнес-процес бронювання мерчу My Little Pony Online, перевірки складських залишків, обробки платежу через PaymentGateway, зняття залишків та фіналізації замовлення у вигляді Activity-діаграми.
- **Вхідні умови**: Покупець перебуває в кошику з обраними позиціями `cartItems` та ініціює оформлення (`submitCheckout`).
- **Вихідні умови**: Замовлення переведено в статус `paid`, залишки товарів списано (`commitStockDeduction`), згенеровано чек і відправлено сповіщення АБО замовлення скасовано (`cancelled`), тимчасовий резерв `Hold` у Storage знято.
- **Out of Scope**: Реєстрація нового користувача (припускається авторизований сеанс) та повернення коштів (Refund UC).

## 2. Ролі та Компоненти
1. **Покупець (User / UI)**: Вводить дані, натискає «Підтвердити замовлення», обирає спосіб оплати, проходить 3D-Secure.
2. **OrderService (Backend)**: Управляє статусами замовлення (`'created'`, `'paid'`, `'cancelled'`), перевіряє `User.status`, створює записи в БД (`insertOrder`, `insertOrderItems`).
3. **InventoryService & Storage**: Перевіряє `stock_quantity`, створює тимчасовий `Hold` (30 хв) та виконує остаточне списання `commitStockDeduction` або скасування `releaseStockReservation`.
4. **PaymentService & PaymentGateway**: Створює платіжну сесію, приймає платіж, відправляє асинхронний Webhook з результатом (`PAID` / `FAILED`).

## 3. Покриття сценаріїв UC-5 (Завдання 2 та 3)
- **UC5-S1 (Основний успішний)**: Успішна перевірка `stock_quantity` -> `insertOrder(status='created')` -> Оплата -> `status='paid'`.
- **UC5-S2 (Успішна оплата / UC-6)**: Отримання Webhook `PAID` -> `commitStockDeduction` -> Сповіщення.
- **UC5-S3 (Помилка оплати / UC-6)**: Webhook `FAILED` -> `status='cancelled'` -> `releaseStockReservation`.
- **UC5-S4 (Блокування повторного списання)**: Виявлення замовлення у статусі `'created'` -> Заборона дублювання запиту.
- **UC5-S5 (Повторна оплата після помилки)**: Створення нового замовлення на основі замовлення зі статусом `'cancelled'`.
- **UC5-S6 (Недостатній залишок / Неавторизований)**: Переривання процесу при `stock_quantity < quantity` або `User.status != 'active'`.
