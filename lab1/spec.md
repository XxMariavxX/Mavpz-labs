# Сутності та їх атрибути:

- **User** :
  * user_id (`UUID`)- унікальний ідентифікатор користувача;
  * username (`VARCHAR`)- ім'я користувача;
  * email (`VARCHAR`)- адреса електронної пошти;
  * password_hash (`VARCHAR`)- хеш пароль;
  * favorite_character_id (`UUID`)- ідентифікатор улюбленого персонажа;
  * registration_date (`DATE`)- дата реєстрації;
  * status (`VARCHAR`)- статус акаунта(`'active', 'inactive', 'banned'`);

- **Character** :
  *  character_id (`UUID`)- унікальний ідентифікатор персонажа;
  *  name (`VARCHAR`)- ім'я персонажа;
  *  pony_type (`VARCHAR`)- тип поні (`Earth Pony, Pegasus, Unicorn, Alicorn`);
  *  location (`TEXT`)- місце проживання персонажа;
  *  cutie_mark_description (`TEXT`)- опис к'ютімарки;
  *  biography (`TEXT`)- біографія;
  *  slug (`VARCHAR`)- унікальний ідентифікатор персонажа для URL;

- **Generation** `покоління франашизи`:
 * generation_id (`UUID`)- унікальний ідентифікатор покоління;
 * code_name (`VARCHAR`)- назва покоління;
 * release_year (`INT`)- рік виходу покоління;
 * description(`TEXT`)- опис покоління;

- **Category**:
 * category_id (`UUID`)- унікальний ідентифікатор категорії;
 * name (`VARCHAR`)- назва категорії;
 * parent_category_id (`UUID`)- ідентифікатор батьківської категорії (для створення дерева підкатегорій);
 * description (`TEXT`)- опис категорії;
 * slug (`VARCHAR`)- унікальний ідентифікатор для URL;

- **Product**:
   * product_id (`UUID`)- унікальний ідентифікатор товару;
   * name (`VARCHAR`)- назва товару;
   * category_id (`UUID`)- ідентифікатор категорії;
   * price (`MONEY`)- вартість товару;
   * stock_quantity (`INT`)- кількість на складі;
   * description (`TEXT`)- опис товару;
   * sku (`VARCHAR`)- артикул (SKU) товару;
   * slug (`VARCHAR`)- унікальний ідентифікатор для URL;

- **Order**:
   * order_id (`UUID`)- унікальний ідентифікатор замовлення;
   * user_id (`UUID`)- ідентифікатор користувача;
   * created_date (`DATE`)- дата створення замовлення;
   * status (`VARCHAR`)- поточний статус (`created, paid, shipped, completed, cancelled`);
   * total_amount (`MONEY`)- загальна сума замовлення;
   * order_number (`VARCHAR`)- унікальний номер замовлення;

- **OrderItem**: 
   * order_id (`UUID`)- ідентифікатор замовлення;
   * product_id (`UUID`)- ідентифікатор товару;
   * quantity (`INT`)- кількість одиниць товару;
   * price_at_purchase (`MONEY`)- зафіксована ціна на момент купівлі;

- **Review**:
   * review_id (`UUID`)- унікальний ідентифікатор відгуку;
   * user_id (`UUID`)- ідентифікатор користувача;
   * product_id (`UUID`)- ідентифікатор товару;
   * comment (`TEXT`)- текстовий коментар;
   * rating (`INT`)- оцінка (рейтинг);
   * published_at (`TIMESTAMP`)- дата та час публікації;


# Унікальні ключі, первинні та зовнішні ключі:

* **User:** 
  * PK: `user_id` (*UUIDv7*)
  * UK: `username`, `email`
  * FK: `favorite_character_id` (Optional)
* **Character:** 
  * PK: `character_id` (*UUIDv7*)
  * UK: `slug` (наприклад, `"twilight-sparkle", "pinkie-pie"`)
* **Generation:** 
  * PK: `generation_id` (*UUIDv7*)
  * UK: `code_name` (наприклад, `"G1"`, `"G4"`, `"G5"`)
* **Category:** 
  * PK: `category_id` (*UUIDv7*)
  * UK: `slug`
  * FK: `parent_category_id` (Optional)
* **Product:** 
  * PK: `product_id` (*UUIDv7*)
  * UK: `sku` (артикул товару), `slug`
  * FK: `category_id`(Optional)
* **Order:** 
  * PK: `order_id` (*UUIDv7*)
  * UK: `order_number`
  * FK: `user_id`
* **OrderItem:** 
  * PK, FK: (`order_id`, `product_id`)
* **Review:** 
  * PK: `review_id` (*UUIDv7*)
  * FK: `user_id`, `product_id`

# Зв'язки між сутностями:

1. **`Generation` -> `Character` (N:M):**
   * Одне покоління містить 1 або багатьох персонажів (`1..N`).
   * Персонаж може належати до одного або декількох поколінь (`1..N`).

2. **`Category` -> `Category` (1:N):**
   * Одна батьківська категорія може мати 0 або більше підкатегорій (`0..N`).
   * Підкатегорія може мати не більше однієї батьківської категорії (`0..1`).

3. **`Category` -> `Product` (1:N):**
   * Одна категорія містить 0 або більше товарів (`0..N`).
   * Кожен товар належить обов'язково до однієї категорії (`1..1`).

4. **`Character` <-> `Product` (N:M):**
   * Один персонаж пов'язаний з одним або багатьма товарами/мерчем (`1..N`).
   * Один товар пов'язаний з одним або багатьма персонажами (`1..N`).

5. **`User` -> `Character` (1:N, Optional / Favorite Pony):**
   * Персонажа можуть обрати улюбленим 0 або більше користувачів (`0..N`).
   * Користувач може обрати не більше одного улюбленого персонажа (`0..1`).

6. **`User` -> `Order` (1:N):**
   * Один користувач може оформити 0 або більше замовлень (`0..N`).
   * Кожне замовлення належить виключно одному користувачу (`1..1`).

7. **`Order` <-> `Product` через `OrderItem` (N:M):**
   * Одне замовлення має містити як мінімум 1 позицію `OrderItem` (`1..N`).
   * Один продукт може фігурувати у 0 або багатьох замовленнях (`0..N`).

8. **`User` -> `Review` (1:N):**
   * Користувач може залишити 0 або більше відгуків (`0..N`).
   * Відгук належить виключно одному користувачу (`1..1`).

9. **`Product` -> `Review` (1:N):**
   * Товар може мати 0 або більше відгуків (`0..N`).
   * Відгук стосується виключно одного товару (`1..1`).
