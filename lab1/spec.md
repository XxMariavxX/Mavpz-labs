# Сутності та їх атрибути:

- **User** (id, username, email, пароль хеш, улюблений персонаж, дата реєстрації, статус акаунта(`active`, `inactive`, `banned`) );

- **Character** (id, ім'я, покоління франшизи(generation), slug, тип поні(`Earth Pony, Pegasus, Unicorn, Alicorn`), локація проживання, опис к'ютімарки, біографія);

- **Generation** `покоління фрнашизи` (назва покоління, унікальний код, рік виходу, опис покоління);

- **Category** (id,назва категорії, батьківська категорія (для створення дерева підкатегорій), опис категорії, slug (унікальний ідентифікатор для URL));

- **Product** (назва товару, категорія, зв'язаний персонаж, вартість, кількість на складі, опис, артикул (SKU)):

- **Order** (покупець, дата створення замовлення, поточний статус (`created, paid, shipped, completed, cancelled`), загальна сума замовлення);

- **OrderItem** (замовлення, товар, кількість одиниць товару, зафіксована ціна на момент купівлі);

- **Review** (автор відгуку(User), оцінений товар(Product), текстовий коментар, оцінка (рейтинг), дата та час публікації)

---

# Унікальні ключі:

* **User:** 
  * Первинний ключ: `user_id` (*UUIDv7*)
  * Унікальні ключі: `username`, `email`
* **Character:** 
  * Первинний ключ: `character_id` (*UUIDv7*)
  * Унікальний ключ: `slug` (наприклад, `"plush-toys", "action-figures"`)
* **Generation:** 
  * Первинний ключ: `generation_id` (*UUIDv7*)
  * Унікальний ключ: `code` (наприклад, `"G1"`, `"G4"`, `"G5"`)
* **Category:** 
  * Первинний ключ: `category_id` (*Incremental ID*)
  * Унікальний ключ: `slug`
* **Product:** 
  * Первинний ключ: `product_id` (*UUIDv7*)
  * Унікальні ключі: `sku` (артикул товару), `slug`
* **Order:** 
  * Первинний ключ: `order_id` (*UUIDv7*)
  * Унікальний ключ: `order_number` (формується за шаблоном, наприклад: `MLP-2026-XXXX`)
* **OrderItem:** 
  * Складений первинний ключ: (`order_id`, `product_id`)
* **Review:** 
  * Первинний ключ: `review_id` (*Incremental ID*)

# Зв'язки між сутностями:connections between them

1. **`Generation` -> `Character` (N:N):**
   * Одне покоління містить 1 або більше персонажів (`1` до `1..N`).
   * Персонаж може належати до одного або декількох поколінь (`1..N`).

2. **`Category` -> `Category` (1:N):**
   * Одна батьківська категорія може мати 0 або більше підкатегорій (`1` до `0..N`).
   * Підкатегорія може мати не більше однієї батьківської категорії (`0..1`).

3. **`Category` -> `Product` (1:N):**
   * Одна категорія містить 0 або більше товарів (`1` до `0..N`).
   * Кожен товар належить обов'язково до однієї категорії (`1..1`).

4. **`Character` -> `Product` (1:N, Optional):**
   * Один персонаж може бути зображений на 0 або багатьох товарах/мерчі (`1` до `0..N`).
   * Товар може бути присвячений конкретному персонажу або бути загальним медіа-товаром без прив'язки до персонажа (`0..1`).

5. **`User` -> `Character` (1:N, Optional / Favorite Pony):**
   * Персонажа можуть обрати улюбленим 0 або більше користувачів (`1` до `0..N`).
   * Користувач може обрати не більше одного улюбленого персонажа (`0..1`).

6. **`User` -> `Order` (1:N):**
   * Один користувач може оформити 0 або більше замовлень (`1` до `0..N`).
   * Кожне замовлення належить виключно одному користувачу (`1..1`).

7. **`Order` <-> `Product` через `OrderItem` (N:M):**
   * Одне замовлення має містити як мінімум 1 позицію `OrderItem` (`1` до `1..N`).
   * Один продукт може фігурувати у 1 або багатьох замовленнях (`1` до `1..N`).

8. **`User` -> `Review` (1:N):**
   * Користувач може залишити 0 або більше відгуків (`1` до `0..N`).
   * Відгук належить виключно одному користувачу (`1..1`).

9. **`Product` -> `Review` (1:N):**
   * Товар може мати 0 або більше відгуків (`1` до `0..N`).
   * Відгук стосується виключно одного товару (`1..1`).
